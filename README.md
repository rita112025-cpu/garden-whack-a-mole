# 菜園打地鼠 Garden Whack-a-Mole

單一 HTML 檔的打地鼠小遊戲，不需要安裝，用瀏覽器開啟 `index.html` 就能玩。

## 規則

每局 30 秒，越到後面角色冒出得越快。

| 角色 | 規則 |
|---|---|
| 地鼠 | +10 |
| 金地鼠（戴皇冠） | +30，停留時間短 |
| 頭盔地鼠 | 要打 2 下，+25 |
| 忍者地鼠 | +50，停留時間最短，開局約 6 秒後才出現 |
| 鬧鐘 | 時間 +3 秒 |
| 炸彈 | −20，連擊歸零 |

- 連續打中 3 次以上，得分加倍；漏掉地鼠連擊歸零。
- 操作：滑鼠、觸控，或鍵盤數字鍵 1–9。
- 最高分存在瀏覽器的 localStorage。

## 執行

直接用瀏覽器開啟 `index.html`。字型從 Google Fonts 載入，離線時會改用系統字型。
